# Discovered Rules — Kandev plugin for Nulab Backlog

> Contains only the five hard rules you chose in Q8 of the practices-discovery interview.

## Mandated

- ALWAYS redact API keys and tokens in logs, error messages, and test output.
- ALWAYS accept only `https` space addresses under `backlog.com`, `backlog.jp`, or `backlogtool.com`.
- ALWAYS run package verification before tagging a release.

## Forbidden

- NEVER put real credentials in the repo, test data, or test artifacts.
- NEVER delete or overwrite a released tag.

### Summary

The switch, home entry, `/backlog` page and logo changes are architecturally sound and the SDK claims hold: nav item, settings action, plugin-controlled error status, and persistence that never touches the connection or key. Two Major gaps remain. The ConnectionView shape is defined differently in entities.md and WF2 and is not reflected in the upstream-change table (R-01). The switch's save and failure behaviour is described as immediate when the host's drafted control defers it to the Save bar (R-02). With two Majors and no Criticals, the verdict is READY, but both should be fixed before code is regenerated.
